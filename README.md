# ערים סמויות: מעבדת המחשה

אטלס של 42 הערים מתוך "ערים סמויות" של איטלו קאלווינו, ולכל עיר שלושה פרומפטים להמחשה.

1. כל פרומפט נבנה בחמש שכבות: רעיון ומתח, מקום וצורה, חומר ומרקם, אור וזמן, קומפוזיציה ומבט, ופלטה.
2. שלוש גרסאות לכל עיר, שונות בזווית ובאור, עם אותו מתח.
3. מעבר בין Midjourney לכלי אחר, העתקה של פרומפט, של שלושה, או של כל 126.
4. הכלאה: המתח והמבט של עיר אחת בתוך המקום והחומר של עיר אחרת.

## מבנה
1. `src/data.js`: הנתונים מהקובץ שהועלה, והשכבות של כל פרומפט.
2. `src/app.js`: הסמלים הגרפיים, בניית הפרומפט והניתוב.
3. `src/app.html`: העיצוב והמבנה.
4. `node build.mjs` מאחד הכול ל-`index.html` (האתר) ול-`dist/artifact.html`.
